## Reviews
- security-guidance plugin (automatic on push), two HIGH findings on the exact kit:
  1. The `cs/*` / `claude/*` push allows also match `git push origin cs/x:main`, a trailing `--force`, `--mirror` and
     `--delete`. The docs say: "A `*` in a Bash rule matches any text, including spaces".
  2. `Bash(git fetch *)` matches `git fetch --upload-pack=<cmd>`, which runs any command: the same bypass as
     `Bash(node *)`.
  Both are addressed by the amendment.

  flag-order gaps remain, e.g. `git commit -m x --amend`, `git switch main -f`, `git branch -f`. Recommendation: don't
  chase every ordering; CLAUDE.md's never-rewrite rule plus branch protection are the guard.
