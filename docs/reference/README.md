# Reference material
Research and inspiration, not what's built. The built roster is in GAME_DESIGN.md §7; the planned one in UNITS.md.

- **RENEGADEX_REFERENCE.md**: Renegade X's full arsenal and economy (infantry, vehicles, aircraft, equipment, costs,
  roles) for both factions. Takeaway: copy its economy shape, not its raw-damage tier curve.
- **KANESWRATH_REFERENCE.md**: Kane's Wrath factions and subfactions, vehicles, aircraft, and the warhead-type ×
  armour-class damage matrix. *Not included yet: copy your downloaded version into this folder.*
