### A1. The brawl's walk: how each command is made, what a Behaviour receives, who calls it

There is no trait. The type is `pub struct Behaviour` with inherent methods, and the per-step entry is `pub fn step(&mut self, endpoint: &mut ClientEndpoint, received: &[(Channel, Vec<u8>, u64)], now_ns: u64, view: &[(u8, [i32; 3])]) -> bool`. step() gives at most one command per client step, and only once the endpoint holds a snapshot whose newest tick has moved; otherwise it counts the step as skipped. The command is built by the private command(). Its walk vector is MOVES[((given / TURN_EVERY + phase) % 16)]: 16 vectors 22.5 degrees apart that sum to 0, TURN_EVERY = 4 commands given, and phase is the first seeded draw. Fire is held on every command. The aim comes from brawl_aim: an enemy in `view`, picked again by the seed every RETARGET_EVERY = 30 commands or when the target leaves view, raised 100 cm; with no enemy in view it aims at a seeded blind point. Nothing reads a position, so the walk is open loop. Each tick it receives the endpoint, `received` (&[] from the lab), the host clock and `view`. `view` is the mirror's room-side frame of the client's newest tick and already includes the brawler's OWN soldier, which brawl_aim filters out. The only caller is npt-lab's runner (scenario.rs); the bots binaries are stubs.

### A4. collide(): how a step is cut; can a steering rule be held forever against a box; effect on everyone-in-view

A command moves v*DT: 600 cm/s x 1/30 s = 20 cm at full vector. collide() moves x, then y. On each axis it stops at the first box face (solids, closed doors, the standing wall, nearby vehicle parts) and sets the position to face ± 0.4 m. A box the soldier starts more than 1 cm inside never blocks it, and nothing pushes a soldier out; soldiers never collide with each other. The position is then snapped to the 1 cm grid, so a per-axis move under 0.5 cm (|m| <= 3 of 127) does nothing. Doors and vehicles are updated before commands in each step. Held forever: against a convex box (a crate, the wall stand-in, a building's outside), a soldier slides on the unblocked axis. It stays stuck only while its steer's perpendicular component is 0 or rounds away (|m| <= 3), that is, with the goal straight behind the box along one axis; examples are north of crate (0,900) or of the wall with |x| small, steering to the origin. Inside a building (concave, one 2 m gap), a straight steer toward an outside goal not in line with the gap pins the soldier in a corner with both axes blocked. In building 2, a steer toward team 1's home slides east, away from the gap, into the SE corner. A vehicle part blocks only while passing, and a part that sweeps into a soldier then never blocks it. Effect on everyone-in-view: a soldier stuck OUTSIDE a building stays in area 0, within 64 m of everyone, so everyone-in-view holds. Only feet inside a footprint with that door shut drop it.
