### Q1 (wtransport 0.7.2): done
- F1.1 The only built-in server constructor is `Endpoint::<Server>::server(ServerConfig)` (wtransport-0.7.2/src/endpoint.rs:128-142): `socket = server_config.bind_address_config.bind_socket()?` (:131), `runtime = Arc::new(TokioRuntime)` (:132), `quinn::Endpoint::new(endpoint_config, Some(quic_config), socket, runtime)` (:134). `quinn::Endpoint::new` takes a `std::net::UdpSocket`, so no custom socket goes under it. HIGH.
- F1.2 All five `with_bind_*` (config.rs:309-366) end in `BindAddressConfig` {AddressV4, AddressV6, Socket(std::net::UdpSocket)} (config.rs:1156-1160); `bind_socket()` returns a `std::net::UdpSocket` (config.rs:1163-1192). `with_bind_socket(self, socket: UdpSocket)` (config.rs:362) takes std's UdpSocket, not an AsyncUdpSocket. `reload_config(.., rebind=true)` calls `self.endpoint.rebind(socket)` with a std socket too (endpoint.rs:167-178). No direct route. HIGH.
- F1.3 The `quinn` feature (Cargo.toml:93 `quinn = []`, adds no dependency) re-exports quinn (lib.rs:144-146 `pub use quinn;`) and opens `IncomingSessionFuture::with_quic_incoming(quic_incoming: quinn::Incoming) -> Self` (endpoint.rs:592-596) and `with_quic_connecting(quinn::Connecting)` (endpoint.rs:605-611). Both drive the QUIC handshake, then `Driver::init(quic_connection.clone())`, `accept_settings()`, `accept_session()` and yield a `SessionRequest` (endpoint.rs:621-635); nothing there touches wtransport's Endpoint. So a caller-built `quinn::Endpoint` works: accept `quinn::Incoming` from it, wrap it. HIGH.
- F1.4 With `quinn` on, `ServerConfig::quic_config()` / `quic_endpoint_config()` (config.rs:255-280) expose the `quinn::ServerConfig` (TLS 1.3 only, ALPN `h3` = WEBTRANSPORT_ALPN: tls.rs:635-657; transport config and migration: config.rs:556-572) and `quinn::EndpointConfig` the builder made, so the caller-built endpoint can reuse exactly wtransport's QUIC/TLS setup. The builder needs a bind address but does not bind (binding happens in `Endpoint::server`, endpoint.rs:131), so any placeholder works. `quinn::ServerConfig` is `Clone` (to be confirmed in quinn-proto, below). HIGH.
- F1.5 Feature state today: npt-net's manifest pulls `wtransport = { workspace = true, optional = true }` with workspace `wtransport = "=0.7.2"` (default features self-signed + ring), so `quinn` is OFF; U3 must add `features = ["quinn"]` (a manifest change for the main session). The feature has no dependencies (Cargo.toml:93), so Cargo.lock does not change. HIGH (lock effect: Cargo records no features in Cargo.lock).

### Q2 (web-transport-quinn 0.13.6): done
- F2.1 Designed for it: `Server::new(endpoint: quinn::Endpoint) -> Self` "Manually create a new server with a manually constructed Endpoint. NOTE: The ALPN must be set to `crate::ALPN`" (web-transport-quinn-0.13.6/src/server.rs:116-124); `Server::accept(&mut self) -> Option<Request>` drives `endpoint.accept()`, the QUIC handshake and `Request::accept(conn)` concurrently in a FuturesUnordered, dropping failed handshakes silently (server.rs:127-165). Per-connection route: `Request::accept(conn: quinn::Connection) -> Result<Request, ServerError>` is public (server.rs:177-189), then `.ok()` / `.respond()` / `.reject()` (server.rs:192-212). The crate's own example builds `quinn::Endpoint` itself and calls `Request::accept` (examples/echo-server-advanced.rs:65-104). quinn is re-exported unconditionally (lib.rs:60 `pub use quinn;`), `ALPN = "h3"` (lib.rs:54). HIGH.
- F2.2 What the built-in `ServerBuilder::with_certificate` sets, for the caller-built endpoint to copy (server.rs:63-98): rustls `builder_with_provider(crypto::default_provider())` (crypto.rs:24-41: process default, else aws-lc-rs, else ring), TLS 1.3 only, no client auth, `alpn_protocols = [b"h3"]`, `quinn::ServerConfig::with_crypto`, `transport_config(transport_config(cc))` = `quinn::TransportConfig::default()` plus an optional congestion factory (client.rs:46-55); it then calls `quinn::Endpoint::server(config, addr)` (server.rs:71), which binds a real UDP socket, so the builder itself cannot take ImpairSocket. The example also sets `max_early_data_size = u32::MAX` (echo-server-advanced.rs:72); the builder does not. HIGH.
- F2.3 `Server` derefs to `quinn::Endpoint` (server.rs:106-112), so stats and close stay reachable. Failed handshakes vanish inside `Server::accept` (server.rs:158-161: `if let Ok(session) = res`), so npt-net should drive `quinn::Endpoint::accept` itself and call `Request::accept` per connection, to count handshake failures (the same shape as wtransport's route). MEDIUM (a design preference, not a constraint).
