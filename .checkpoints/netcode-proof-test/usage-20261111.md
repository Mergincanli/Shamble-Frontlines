## The three biggest savings that leave the judge, the marks and every pass bar as they are
1. **Builders restart fresh from their notes.** A builder hands over to a fresh copy of itself at each fix group (or
   about every 40 calls), from the notes file CHECKPOINTS.md already makes it keep; cargo and test output goes to files
   under `.gate/` and is read by grep, not whole. The same tests, gate and counted runs. Estimate: 8-12 M a day. A spend
   cut then also loses one stage, not the whole run.
2. **A lean main session.** Compact at about 35-40 % instead of 70 %; the main session reads the card and the agents'
   short summaries, never diffs, plan files or whole reports; one wake per workflow run, no polling. Estimate: 7-10 M
   a day.
3. **One review packet per round.** A script cuts one packet per round: the diff, the plan and carry lines it is judged
   against (by line range), the last round's findings. Each reviewer starts from it instead of hunting through the
   1,400-line plan on its own, and still reads any file and runs any test it wants. Estimate: 4-6 M a day.
