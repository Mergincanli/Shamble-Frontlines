- F9 (reasoned, matches F8) FNV-1a is a T-function: output bit k depends only on input bits 0..k; per step a byte enters bits 0-7 and the odd multiply is a bijection. So: a change in ONE byte is always caught (certain); a change whose lowest changed bit position is flipped an odd number of times is always caught (that output bit is their parity, RFC 9923 sec 1.4 generalised); otherwise the low bits up to that position are blind: worst case 8 bits (changes only in bit 7 of bytes, even count) -> 56 working bits, miss chance ~2^-56 = 1.4e-17 per compared tick. XXH64: all 64 bits good on every class.
