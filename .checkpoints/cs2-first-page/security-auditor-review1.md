## 07:31:21 UTC serve.mjs live probe (scratchpad sec-review1/probe-serve.mjs, ephemeral port, scratch root; reviewed code imported, nothing in the worktree written)
- Refused as they must: ../, %2e%2e, ..%2f, ..;/, overlong %c0%ae (400), %u002e (400), /index.html. and %20 (type table), link to /etc/hostname, link to /dev/zero, a FIFO, a folder named dir.js, ..foo.js, absolute-form target (400), CONNECT (closed), TRACE/OPTIONS (405), HTTP/1.0 without Host (421), HTTP/1.1 without Host (Node 400), Host with trailing dot / leading-zero port / [::ffff:127.0.0.1] / decimal IP (421). Two Host headers: Node keeps the first (a browser never sends two). Defaults read: headersTimeout 60000, requestTimeout 300000, keepAliveTimeout 5000, timeout 0 (no idle limit on a slow reader), maxConnections unset, maxHeaderSize 16384.
- FINDING S1 (Medium) serve.mjs:120-122 stream.pipe(response): an aborted download leaves the file stream paused and its descriptor open for good. Shown: 40 GETs of an 8 MiB .js, client socket destroyed after the first chunk -> /proc/self/fd 25 -> 63, 40 descriptors still on big.js after gc(). pipe() only unpipes on the response's close (Node streams); fs.ReadStream closes only on end/error. Reach: each reload or navigation during a load leaks one; a local client or a page with loopback access can run the process out of descriptors (then every file answers 404/500) - local DoS of the dev tool, restart clears it. No test covers an aborted response. Fix: stream.pipeline(stream, response, () => {}) (node:stream) or response.on('close', () => stream.destroy()); test: N aborted downloads, descriptor count back to start (Linux /proc).
- FINDING S2 (Low) serve.mjs:70: the content type comes from the requested name, not the resolved file: an in-folder link alias.js -> serve.mjs answered 200 with the server's source as JavaScript (shown). Needs a link planted inside the folder (none in dist; the zip holds none). Fix: take the type from path.extname(real) (or require both).
- 07:32:16 UTC FINDING S3 (Medium; adds reach to engine-architect's F2, same root) worker-link.ts:89-117: once failure is set, frame() returns before it drains #returned, but #takeBlock still accepts every block and pushes the previous one into #returned. Shown with the real worker-link.ts (scratchpad sec-review1/link-after-failure.mts, Node type stripping): ready, one good block, an error message (host.ts:80-82 answers an unknown message with an error and keeps ticking), then 300 blocks with pad 1 MiB and frames drawn: 0 input posts, 297.6 MiB of ArrayBuffers held after gc(). ## 07:36:04 UTC Windows forms, by reasoning (not tried on Windows)
- Lexical: backslash, colon (drive, ADS ::$DATA, :Zone.Identifier) and NUL refused before join (serve.mjs:65); win32 join/relative keep every request under the root. Trailing dot/space: path.extname gives '.' or '.html ' -> not in the table (seen on Linux: /index.html. and %20 -> 404). 8.3 names: a short name's extension is the long one's first three letters, so a disallowed long type cannot become .js/.css; .html/.json/.wasm become .HTM/.JSO/.WAS (refused). Device names (CON.js, NUL.html, COM1.js): native realpath (libuv fs__realpath -> GetFinalPathNameByHandleW) fails or returns a non-\\?\ path -> error -> 404; any result outside the root is refused by serve.mjs:80-81. Residual: CreateFileW on a real COM port (Bluetooth serial) may block a thread-pool thread (unverified).
- FINDING S4 (Low, availability, fail-safe) serve.mjs:90 vs 75: the root is resolved by fs.realpathSync (Node's JS walker: lstat per part, keeps an 8.3 short name or a subst drive letter as given; checked: its source has no binding.realpath) and each request by fs/promises realpath (native binding.realpath: GetFinalPathNameByHandleW gives long names, the volume behind a subst drive, UNC for a mapped drive). A folder reached through C:\\Users\\MUSTAF~1\\..., a subst drive or a mapped drive makes every file look outside -> every request 404. Case differences are fine (win32.relative lowercases). Fix: realpathSync.native(root).
- Port 80: a browser drops :80 from Host, so own='127.0.0.1:80' never matches (every request 421). Nit; the server prints 4173 by default.
