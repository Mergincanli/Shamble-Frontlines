  - Intro: GAS = "highly-flexible framework for building abilities and attributes" (quoting Epic). Provides: level-based abilities with optional costs and cooldowns; manipulating numerical Attributes; status effects; GameplayTags on actors; spawning VFX/SFX; replication of all of it. Confirmed in source.
  - §4.2 Tags: hierarchical names Parent.Child.Grandchild registered with GameplayTagManager, defined ahead of time (DefaultGameplayTags.ini). ASC counts tags (FGameplayTagCountContainer TagMap count; HasTag false at 0). Loose tags not replicated; tags from GEs replicated. Confirmed.
  - §4.3 Attributes: BaseValue = permanent; CurrentValue = BaseValue + temporary GE mods. Instant and Periodic GEs change BaseValue; Duration and Infinite change CurrentValue. Confirmed.
  - §4.3.3 Meta attributes: Damage as placeholder meta attribute, modified by buffs/debuffs in an execution calc, then distributed by the AttributeSet (e.g. shield before health); no persistence. Confirmed.
  - §4.5 GEs (offset 0-100000): Instant = immediate permanent BaseValue change, no tags even for a frame; Duration = temporary CurrentValue + tags removed on expiry; Infinite = never expires on its own. Period: Duration/Infinite may apply modifiers/executions every X s; periodic treated as instant on BaseValue and "cannot be predicted". Confirmed.
  - §4.5.4 Modifier ops: Add, Multiply, Divide, Override; formula ((InlineBaseValue + Additive) * Multiplicitive) / Division; Override replaces final value, last applied wins; Multiply and Divide modifiers are SUMMED before applying (unexpected results; changing needs engine code). Modifiers are "the only way to predictively change an Attribute". Confirmed.
  - §4.5.5 Stacking: Aggregate by Source (stack instance per source ASC) vs by Target (one instance, shared limit); stacking only for Duration and Infinite; duration refresh / period reset / expiration policies exist but are only described by editor tooltips. Confirmed.
  - §4.5.7-8 tags on GE: Granted Tags (removed on GE removal), Application Tag Requirements, Ongoing Tag Requirements (GE toggles on/off), Remove GEs with Tags; Immunity via GrantedApplicationImmunityTags / query. Confirmed.
  - §4.5.9 Spec: instance of a GE (class ref, level, creator), mutable before apply; SetByCaller = map tag->float on the spec; missing SetByCaller -> runtime error, uses 0. Confirmed.
  - Intro lists cooldown prediction as open issue ("GameplayEffect latency reconciliation"). Confirmed (summary).
