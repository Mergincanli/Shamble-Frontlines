## 4. Marks at step 2.5 and Slice 1

The profiles (part 13, 0001:583-590; restated 0001:1492-1499), latency as the round trip, every run also reordering:

| Profile | Round trip | Jitter | Loss | Each direction |
|---|---|---|---|---|
| P0 | 0 ms | none | 0 % | 0 ms, no jitter, 0 % |
| P1 | 50 ms | ±10 ms | 1 % | 25 ms ± 5 ms, 1 % |
| P2 | 100 ms | ±20 ms | 2 % | 50 ± 10 ms, 2 % (about 4 % of round trips lose a packet: 1 − 0.98 × 0.98 = 3.96 %) |
| P3 | 150 ms | ±30 ms | 5 % | 75 ms ± 15 ms, 5 % |
| P4 | 200 ms | ±40 ms | 5 % | 100 ms ± 20 ms, 5 % |
| B1 | P2 plus one burst of 1 s at 100 % loss | | | |

Rule: each direction carries half the latency and a uniform jitter of ± half the jitter, and loses packets at the profile's rate independently (OQ-0001-16). The per-direction figures for P1, P3 and P4 are that rule's arithmetic; only P2's "50 ± 10 ms each way" is printed in the draft (0001:1499). Reorder step on L1: 1 % of adjacent datagram pairs swapped per flow and direction; a mark naming reordering counts only if the measured reorder share is above 0; one run at P4 recorded (0001:596-600). L1 = simulated time, logic marks only (counts, shares, hashes), never a time mark (0001:1466-1467).
