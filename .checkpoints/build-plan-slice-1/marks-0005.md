# ADR 0005's pass marks on the real game (digest-0005, test-engineer, 2026-11-14)

A reading digest for the build plan of foundation steps 2.4, 2.5 and Slice 1. It decides nothing and changes no number:
every number is copied from `docs/adr/0005-content-abilities-assets.md` (cited as 0005:NNNN), `docs/SPIKE_PLAN.md`
(SP:NNNN) or ADR 0002's migration plan (0002:NNNN). "First real-game build" names the earliest build in ADR 0002's
order (2.4, 2.5, 2.6, Slice 1 … Slice 6) whose content and code can show the mark honestly; "first-model CS" is the
change-set where the first Blender soldier (one GLB, exported plain, named colour slots) replaces Slice 1's code-built
stand-in. Where a mark has parts that become measurable at different builds, the cell names each half.

Abbreviations, as the draft uses them (0005:2203-2264): CI the gate v2's runners (counts, verdicts, hashes, bytes; never
a time); RS one vCPU of the reference server; ML the minimum laptop; RD the recommended desktop; MAC the macOS machine
(Safari); MP Mustafa's PC in Brave (judgement only). C the labelled fuzz corpus of PM-0005-4. SS the stress scene; LS
ADR 0003's look-test scene; BS ADR 0003's benchmark scene; T a timed run set (3 runs × 36,000 ticks); V the 3 % spread
rule; P2 100 ms, ±20 ms, 2 %. "Wasm" means wasm32 in Node and in a Worker in Chromium, Firefox and WebKit (CI).
