# ADR 0004 pass marks: digest for the build plan (foundation 2.4, 2.5, Slice 1)

Task digest-0004 (rust-reviewer, 2026-11-14). A reading digest only: no number changed, no mark added, nothing decided.
Sources: `docs/adr/0004-simulation-core.md` (cited as 0004:NNNN), `docs/SPIKE_PLAN.md` (SP:NNNN), and for slice
names only `docs/adr/0002-code-structure-build-toolchain.md` (0002:NNNN).

Abbreviations, as the draft's key defines them (0004:1030-1117): RS = one pinned vCPU of the reference server (CCX23,
x86-64, `fsn1`, rented per run); ML = minimum laptop (Wasm marks in Chrome and Firefox on Windows 11, Edge reported);
RD = recommended desktop; MAC = Safari on a Mac; CI = gate v2 runners, "counts, hashes and checks only, never a time";
A64 = a native AArch64 machine. SS = the stress scene (N = 48, 16v16v16, 15 big vehicles of which 4 very large units
of at least 20 parts, 300 live projectiles, 8 active effects per soldier = 384, DM_Tri-sized 3D greybox); O3 = the
Octopon-3 greybox; TB = two-floor test building (three damage stages); LB = ledge block (ledges 2.5, 2.9, 3.0, 3.1 m;
platforms 1.2, 2.5, 4.0 m with ramps); BR = box-only legacy parity scenes; M10 = bots-only match of 18,000 ticks.
T = timed set: 3 runs, each 900 warm-up + 36,000 measured ticks; V = the 3 run medians within 3 %. A time mark with no
statistic is a p99. "Wasm ≤ 2 × native" is read on one machine (ML). The seven determinism targets (SP:339-341,
PM-0004-19): native, Node, Chromium, Firefox, WebKit (Playwright), real Safari on MAC, Windows on ML (Chrome and Firefox).
Build order used for "first build": 2.4 generated types; 2.5 client + local server skeleton (Worker, loopback, empty
scene, first recording's per-tick hashes natively twice and in Wasm); Slice 1 move and shoot (N = 12); Slice 2 bots,
three teams, navbake, navigation, first map (a nightly 30-minute bot room at N = 48, 0002:1492-1494); Slice 3 online;
Slice 4 loop (economy, abilities, effects; ADR 0004 adds player records, pickups, structure states and damage stages,
0004:1256); Slice 5 Octopon-3 and editor; Slice 6 scale to 48, stress scene, reference server, final 60 Hz call.
"Code rests on it": my reading of what would be redone if the mark failed (the draft's rollbacks, 0004:1207-1212, where
it names one).
