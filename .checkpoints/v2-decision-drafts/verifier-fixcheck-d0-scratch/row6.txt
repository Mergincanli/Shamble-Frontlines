(the exact words ADR 0006 line 489 quotes); the attribute's lead: "requests originating from a different site, including the scheme, from the site that set the cookie". MDN `Glossary/Site` (200, fetched 20:34): "For this more precise definition a site is determined by the registrable domain portion of the domain name. The registrable domain consists of an entry in the Public Suffix List plus the portion of the domain name just before it." and "Browsers ... must only send SameSite cookies to the same site that set them." Note: the same Glossary page adds "In some contexts, the scheme is also considered ... This stricter definition is applied in the rules for handling SameSite cookies." So for SameSite a site is the registrable domain plus the scheme. The drafts' conclusion holds (page and lobby are both HTTPS), but "a site being the registrable domain" is a simplification. | optional, for precision: ADR 0001 line 489–490 "a site being the registrable domain" → "a site being the registrable domain and the scheme (https here)"; the same in ADR 0006 line 489 and lines 936–937 |
