75: §Portability
76: Due to differences in endianness and type sizes, data fed by Hash to a Hasher
77: should not be considered portable across platforms. Additionally the data passed by most
78: standard library types should not be considered stable between compiler versions.
79: This means tests shouldn’t probe hard-coded hash values or data fed to a Hasher and
80: instead should check consistency with Eq.
81: Serialization formats intended to be portable between platforms or compiler versions should
82: either avoid encoding hashes or only rely on Hash and Hasher implementations that
83: provide additional guarantees.
