439: 1.38.0 · Sourcepub fn div_euclid(self, rhs: f32) -> f32
440: Calculates Euclidean division, the matching method for rem_euclid.
441: This computes the integer n such that
442: self = n * rhs + self.rem_euclid(rhs).
443: In other words, the result is self / rhs rounded to the integer n
444: such that self >= n * rhs.
445: §Precision
446: The result of this operation is guaranteed to be the rounded
447: infinite-precision result.
448: §Examples
449: let a: f32 = 7.0;
450: let b = 4.0;
451: assert_eq!(a.div_euclid(b), 1.0); // 7.0 > 4.0 * 1.0
452: assert_eq!((-a).div_euclid(b), -2.0); // -7.0 >= 4.0 * -2.0
453: assert_eq!(a.div_euclid(-b), -1.0); // 7.0 >= -4.0 * -1.0
454: assert_eq!((-a).div_euclid(-b), 2.0); // -7.0 >= -4.0 * 2.0
455: 1.38.0 · Sourcepub fn rem_euclid(self, rhs: f32) -> f32
456: Calculates the least nonnegative remainder of self when divided by
457: rhs.
458: In particular, the return value r satisfies 0.0 <= r < rhs.abs() in
459: most cases. However, due to a floating point round-off error it can
460: result in r == rhs.abs(), violating the mathematical definition, if
461: self is much smaller than rhs.abs() in magnitude and self < 0.0.
462: This result is not an element of the function’s codomain, but it is the
463: closest floating point number in the real numbers and thus fulfills the
464: property self == self.div_euclid(rhs) * rhs + self.rem_euclid(rhs)
465: approximately.
